# ErnestoMusca S.R.L.

Sito web statico di ErnestoMusca S.R.L.

## Struttura

- `dist/` — file statici pubblicati (HTML, CSS, JS)
- `package.json` — script di sviluppo

## Sviluppo locale

```bash
npm run dev
```

Avvia un server locale su `http://localhost:4173` servendo i file presenti in `dist/`.

## Verifica JS

```bash
npm run check
```
